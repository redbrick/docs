# Sewer Cluster

## What is the Sewer Cluster?

The sewer cluster is a trio of systems named after the teenage mutant ninja turtles. They make up redbrick dev cluster.

## What does it do?

The sewer cluster is hooked up with nomad and consul just like aperture, so it's the perfect place to test new services. The sewer cluster boxes also
have GPUs in them, which lets them run AI workloads. Anything hosted by redbrick that uses an AI model is hosted here.
